# 一起等你 · 孕期检查日历

中文孕期检查计划，适配手机和电脑。每项检查右上角的 **? Help** 打开简明说明，包括检查内容、建议时间及就诊准备。支持关闭按钮、Esc 和点击弹窗外关闭。

## 运行

直接打开 `dist/index.html`，无需安装依赖。部署任何静态托管服务时，使用 `dist` 作为网站根目录。

也可运行 `node server.cjs`，按照窗口提示在同一可信家庭网络共享。详见 `使用说明.txt`。

## 功能边界

- 静态发布版：记录保存在各自浏览器，可导出备份；没有云端数据库或跨设备自动同步。
- 家庭服务版：电脑开机运行时可在家庭网络共同记录。
- 手机提醒：需自行导入导出的 ICS 文件并启用日历通知；网站没有后台推送。

预产期按医生核定修改，建议日期自动重算；实际预约保留。检查项目与日期仅供规划参考，以医生个体化管理及医院安排为准。医学参考链接位于页面底部。

## 文件

`dist/index.html` 页面；`dist/app.js` 时间轴与记录；`dist/help.js` 帮助弹窗；`dist/style.css` 样式。

请勿提交 `.family-key`、`family-data.json`、导出的健康记录、访问令牌或其他个人运行数据。
