就诊前，一起确认

向目标医院核实：周六产科与超声是否开放、NT/大排畸放号时间、建档材料、产检与分娩院区；向居住地社区核实母子健康手册。身份证、医保凭证、既往报告和用药清单随身携带。

及时就医：明显单侧腹痛、晕厥、肩尖痛、大量出血，或孕中晚期流液、明显胎动减少等情况，请及时就医，不等待计划日期；紧急情况拨打120。
